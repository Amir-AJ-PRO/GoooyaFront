## 🎯 همین! دیگه هیچ کاری لازم نیست!

سیستم به صورت **کاملاً خودکار**:

✅ Token ها را رمزنگاری می‌کند
✅ قبل از expire، refresh می‌کند (5 دقیقه قبل)
✅ اگر 401 دریافت کرد، خودش refresh می‌کند
✅ از refresh های موازی جلوگیری می‌کند
✅ درخواست‌های در انتظار را در صف نگه می‌دارد
✅ در صورت expire شدن session، به login redirect می‌کند
✅ وقتی به tab برمی‌گردید، token را بررسی می‌کند
✅ از XSS, CSRF, Brute Force محافظت می‌کند

## 📝 مثال کامل Login Page

```typescript
'use client';

import { useState } from 'react';
import { useRouter } from 'next/navigation';
import { useRequestOTP, useVerifyOTP } from '@/hooks/useAuthMutations';
import { useAuth } from '@/contexts/AuthContext';

export default function LoginPage() {
  const [phone, setPhone] = useState('');
  const [code, setCode] = useState('');
  const [step, setStep] = useState<'phone' | 'otp'>('phone');
  
  const router = useRouter();
  const { login } = useAuth();
  const requestOtp = useRequestOTP();
  const verifyOtp = useVerifyOTP();

  const handleRequestOtp = async (e: React.FormEvent) => {
    e.preventDefault();
    await requestOtp.mutateAsync({ phone });
    setStep('otp');
  };

  const handleVerifyOtp = async (e: React.FormEvent) => {
    e.preventDefault();
    const result = await verifyOtp.mutateAsync({ phone, code });
    
    login({
      id: result.user.phone,
      name: result.user.full_name || result.user.phone,
      email: result.user.email || '',
      type: result.user.is_staff ? 'admin' : 
            result.user.is_agent ? 'agent' : 'user',
      phone: result.user.phone,
    });
    
    router.push('/user');
  };

  return (
    <div className="min-h-screen flex items-center justify-center">
      {step === 'phone' ? (
        <form onSubmit={handleRequestOtp}>
          <input
            type="tel"
            value={phone}
            onChange={(e) => setPhone(e.target.value)}
            placeholder="09123456789"
          />
          <button type="submit">ارسال کد</button>
        </form>
      ) : (
        <form onSubmit={handleVerifyOtp}>
          <input
            type="text"
            value={code}
            onChange={(e) => setCode(e.target.value)}
            placeholder="کد 6 رقمی"
          />
          <button type="submit">تایید</button>
        </form>
      )}
    </div>
  );
}
```

## 🔥 ویژگی‌های خودکار

### ✨ Auto-Refresh
Token ها **5 دقیقه قبل** از expire به صورت خودکار refresh می‌شوند.

### ✨ Smart 401 Handling
اگر API ارور 401 داد، خودکار refresh می‌شود و درخواست دوباره ارسال می‌شود.

### ✨ Queue System
اگر 10 درخواست همزمان refresh بخواهند، فقط **یکی** refresh می‌شود و بقیه منتظر می‌مانند.

### ✨ Encryption
Token ها با رمزنگاری در localStorage ذخیره می‌شوند.

### ✨ Rate Limiting
محدودیت تعداد درخواست برای جلوگیری از حمله.
